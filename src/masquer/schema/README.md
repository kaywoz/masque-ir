# Defender XDR schema

`defender_tables.json` lists the advanced-hunting tables, their column names
and data types, and the ActionType values named in the docs pages. It is
generated by `tools/extract_schema.py` from the Microsoft Learn pages
(Defender XDR, "advanced-hunting-*-table"), read from the public mirror
`merill/defender-docs-mirror` at the commit in `source_commit`. No
description text is copied.

Refresh:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/merill/defender-docs-mirror /tmp/ddm
git -C /tmp/ddm sparse-checkout set --no-cone '/defender-xdr/advanced-hunting-*-table.md'
python3 -I tools/extract_schema.py /tmp/ddm/defender-xdr "$(git -C /tmp/ddm rev-parse HEAD)"
```
